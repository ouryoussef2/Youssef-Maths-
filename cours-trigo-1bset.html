1. Rappels et angles associés

Activité 1 On considère le cercle trigonométrique (C) muni d'un repère orthonormé direct (O, i, j) et M le point d'abscisse curviligne x.
  1. Placer sur (C) les points associés à −x, π − x, π + x et π2 − x.
  2. En déduire par symétrie leurs cosinus et sinus en fonction de cos x et sin x.

1.1 Relations fondamentales et valeurs usuelles

Propriétés fondamentales Pour tout réel x et tout entier relatif k ∈ ℤ :
  • −1 ≤ cos x ≤ 1  et  −1 ≤ sin x ≤ 1
  • cos²x + sin²x = 1
  • cos(x + 2kπ) = cos x  et  sin(x + 2kπ) = sin x
  • Pour x ≠ π2 + kπ : tan x = sin xcos x, tan(x + kπ) = tan x et 1 + tan²x = 1cos²x.

1.2 Angles associés

Formules des angles associés Pour tout réel x :
  • cos(−x) = cos x  |  sin(−x) = −sin x  |  tan(−x) = −tan x
  • cos(π − x) = −cos x  |  sin(π − x) = sin x  |  tan(π − x) = −tan x
  • cos(π + x) = −cos x  |  sin(π + x) = −sin x  |  tan(π + x) = tan x
  • cos(π2 − x) = sin x  |  sin(π2 − x) = cos x
  • cos(π2 + x) = −sin x  |  sin(π2 + x) = cos x
Application 1 Simplifier pour tout x ∈ ℝ :
A(x) = cos(π + x) + sin(π2 − x) − sin(π − x) + cos(π2 + x)

2. Formules d'addition

Propriété (Formules d'addition) Pour tous réels a et b :
  • cos(a − b) = cos a cos b + sin a sin b
  • cos(a + b) = cos a cos b − sin a sin b
  • sin(a + b) = sin a cos b + cos a sin b
  • sin(a − b) = sin a cos b − cos a sin b
  • tan(a + b) = tan a + tan b1 − tan a tan b  et  tan(a − b) = tan a − tan b1 + tan a tan b (sous réserve d'existence)
Exemple Calculer cos(π12) et sin(π12) en remarquant que π12 = π3 − π4 :
cos(π12) = cos(π3)cos(π4) + sin(π3)sin(π4) = 12·√22 + √32·√22 = √2 + √64
Application 2
  1. Calculer cos(7π12) et tan(π12).
  2. Montrer que cos x + sin x = √2 cos(x − π4) pour tout x ∈ ℝ.

3. Formules de duplication et de linéarisation

Formules de l'angle double (duplication) Pour tout réel x :
  • sin(2x) = 2 sin x cos x
  • cos(2x) = cos²x − sin²x = 2cos²x − 1 = 1 − 2sin²x
  • tan(2x) = 2 tan x1 − tan²x (pour x ≠ π4 + kπ2 et x ≠ π2 + kπ)
Formules de linéarisation Pour tout réel x :
cos²x = 1 + cos(2x)2     |     sin²x = 1 − cos(2x)2
Formules en fonction de t = tan(x2) Pour x ≠ π + 2kπ, en posant t = tan(x2) :
cos x = 1 − t²1 + t²   |   sin x = 2t1 + t²   |   tan x = 2t1 − t²
Application 3 Sachant que cos x = −35 et x ∈ [π2, π], calculer sin x, cos(2x), sin(2x) et cos(x2).

4. Équations et inéquations trigonométriques

Équations fondamentales (k ∈ ℤ)
  • cos x = cos α ⟺ x = α + 2kπ  ou  x = −α + 2kπ
  • sin x = sin α ⟺ x = α + 2kπ  ou  x = π − α + 2kπ
  • tan x = tan α ⟺ x = α + kπ (avec x, α ≠ π2 + kπ)
Transformation de a cos x + b sin x = c Si (a, b) ≠ (0, 0), on pose r = √(a² + b²). Il existe un unique φ ∈ [0, 2π[ tel que cos φ = ar et sin φ = br, d'où :
a cos x + b sin x = r cos(x − φ)
L'équation admet des solutions si et seulement si |c| ≤ √(a² + b²).
Exercice de synthèse
  1. Résoudre dans ℝ puis dans [0, 2π[ : 2cos²x − 3cos x + 1 = 0.
  2. Résoudre dans [−π, π] : √3 cos x − sin x = 1.
  3. Résoudre dans [0, 2π[ l'inéquation : 2sin x − √3 ≥ 0.
