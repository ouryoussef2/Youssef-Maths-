1. Généralités sur les suites numériques

Activité 1
  1. Pour chaque liste, écrire les deux nombres qui prolongent la séquence :
    a. 5, 9, 13, 17, …
    b. 2, 6, 18, 54, …
    c. 1, 18, 127, 164, …
  2. Quelle règle permet, dans chacune de ces listes, d’obtenir un terme à partir du terme qui le précède ?

Chacune de ces listes est appelée une suite numérique ; les nombres qui la constituent sont les termes de la suite.

1.1 Définition et notation

Définition Soit p un entier naturel et I = {n ∈ ℕ / n ≥ p}. Toute fonction numérique u définie sur I est appelée suite numérique.
  • L’image par u d’un entier n de I est notée un.
  • un est appelé le terme général de la suite u.
Remarques
  • Une suite se note (un)n∈I ou (un)n≥p.
  • Si I = ℕ : (un), (un)n, (un)n≥0 ou (un)n∈ℕ.
  • Si I = ℕ* : (un)n≥1 ou (un)n∈ℕ*.
  • Le réel up est le premier terme de la suite (un)n≥p.
Exemples
  • La suite (un)n≥0 des multiples de 4 : u0 = 0, u1 = 4, u3 = 12.
  • 1, 10, 100 et 1000 sont des termes de (vn)n≥0 avec vn = 10n.
  • La suite de terme général wn = √(n − 3) est définie pour n ≥ 3 ; on la note (wn)n≥3, son premier terme est w3 = √(3 − 3) = 0.
Application 1 Soit (un) définie sur ℕ* par un = 5 − 2n.
  1. Déterminer les trois premiers termes de (un).
  2. Exprimer, pour tout n ∈ ℕ*, les nombres un − 1, un+1, u2n et u2n+1.
  3. Déterminer l’entier n pour lequel un = 5912.
Deux types de suites
  • Suite définie explicitement : le terme général est une fonction connue de l’entier n.
  • Suite récurrente : définie par son premier terme et une relation permettant de calculer un terme à partir d’un ou plusieurs termes précédents.
Exemples
u0 = 2 ; un+1 = 3un − 1   |   v0 = 2, v1 = −1 ; vn+2 = 2vn+1vn   |   wn = 2n − 4n

(un) et (vn) sont récurrentes ; (wn) est définie explicitement.

Application 2 Soient u0 = 1, un+1 = un1 + 2un et v0 = 1, v1 = 3, vn+2 = 3vn+1 − vn.
  1. Déterminer u1, u2, v2, v3.
  2. Démontrer par récurrence que, pour tout n ∈ ℕ, un = 12n + 1.

1.2 Suites majorées – minorées – bornées

Activité 2 Soit un = 2n + 3n + 1, n ∈ ℕ.
  1. Prouver que un ≤ 3 pour tout n : on dit que (un) est majorée par 3.
  2. Prouver que un ≥ 2 : (un) est minorée par 2.
  3. Conclure que 2 ≤ un ≤ 3 : (un) est bornée.
Définition Soit (un)n∈I une suite numérique.
  • Majorée ssi il existe un réel M tel que (∀n ∈ I) : un ≤ M.
  • Minorée ssi il existe un réel m tel que (∀n ∈ I) : un ≥ m.
  • Bornée ssi elle est à la fois majorée et minorée.
Exemple (rattrapage 2013) u0 = 2 et un+1 = 15un + 45. Montrons par récurrence que (un) est minorée par 1.
Application 3 u0 = 5, un+1 = 6un − 8un. Démontrer que un ≥ 4 pour tout n ∈ ℕ.
Exercice 1 u0 = 0, un+1 = 2un + 1un + 2. Montrer que (∀n ∈ ℕ) : 0 ≤ un ≤ 1.
Propriété (un)n∈I est bornée ssi (∃M ∈ ℝ*+) ; (∀n ∈ I) : |un| ≤ M.
Exemple un = 2cos(n² + 2) + 1 : on a |un| ≤ 3 pour tout n, donc (un) est bornée.

1.3 Monotonie d’une suite

Définition (un)n∈I est
  • croissante ssi (∀p, q ∈ I) : p < q ⇒ up ≤ uq ;
  • décroissante ssi (∀p, q ∈ I) : p < q ⇒ up ≥ uq ;
  • constante ssi (∀p, q ∈ I) : p < q ⇒ up = uq.
Propriété
  • Croissante ⟺ (∀n ∈ I) : un+1 ≥ un
  • Décroissante ⟺ (∀n ∈ I) : un+1 ≤ un
  • Constante ⟺ (∀n ∈ I) : un+1 = un
Exemples
  • xn = 2n − 3 : xn+1 − xn = 2(n+1) − 3 − (2n − 3) = 2 > 0. Donc (xn) est strictement croissante.
  • yn = 5 × (23)n : yn+1 − yn = 5 × (23)n × (23 − 1) = 5 × (23)n × (−13) < 0. Donc (yn) est strictement décroissante.
Application 4 Déterminer le sens de variation de (un)n∈ℕ :
  1. un = 2n + 3
  2. un = n² + 3n
  3. un = √(n + 2)
  4. un = (−2)n
Remarques Pour (un)n≥p : si elle est croissante, (∀n ≥ p) : un ≥ up ; si elle est décroissante, (∀n ≥ p) : un ≤ up.
Application 5 u0 = 8, un+1 = 6 − 8un.
  1. Déterminer u1 et u2.
  2. Démontrer que un > 4 pour tout n ∈ ℕ.
  3. a. Prouver que un+1 − un = (2 − un)(un − 4)un.
    b. Déterminer le sens de variation de (un).
    c. En conclure que un ≤ 8 pour tout n.
Exercice 2 v0 = 3, vn+1 = 12(vn + 4vn).
  1. Calculer v1 et v2.
  2. Montrer que (vn) est minorée par 2.
  3. Étudier la monotonie de (vn).
  4. En déduire que (vn) est majorée par 3.

2. Suite arithmétique

2.1 Définitions

Activité 3 Soit un = 5n − 1, n ∈ ℕ.
  1. Contrôler que u1 = u0 + 5, u2 = u1 + 5, u3 = u2 + 5.
  2. Établir que un+1 = un + 5 pour tout n.

Chaque terme s’obtient en ajoutant 5 au précédent : la suite est arithmétique de raison r = 5.

Définition (un)n∈I est arithmétique s’il existe un réel r tel que (∀n ∈ I) : un+1 = un + r. Le réel r est la raison.
Technique On calcule un+1 − un : si le résultat est une constante r indépendante de n, la suite est arithmétique de raison r.
Exemples Montrons que un = −32n + 5 est arithmétique, et que vn = n² + 5 ne l’est pas.
Application 6 u0 = 3, un+1 = 4un − 4un, et vn = 1un − 2. Démontrer que (vn) est arithmétique, donner sa raison et son premier terme.

2.2 Terme général

Propriété Si (un)n∈I est arithmétique de raison r et de premier terme up :
un = up + (n − p) × r   pour tout n ≥ p.
Remarque Si p = 0 : un = u0 + nr. Si p = 1 : un = u1 + (n − 1)r.
Exemple 1 r = 12 et u6 = 3 : u30 = u6 + (30 − 6) × 12 = 15.
Exemple 2 u0 = 5 et u100 = −45 : 100r = −50, donc r = −12 et un = 5 − 12n.
Application 7 (un) arithmétique, u1 = −4, r = 3.
  1. Déterminer u6, u15, u80.
  2. Donner un.
  3. Le nombre 146 figure-t-il parmi les termes ?

2.3 Somme de termes consécutifs

Propriété Si (un) est arithmétique et p ≤ n :
Sn = up + up+1 + ⋯ + un = (n − p + 1) × un + up2
up : premier terme de la somme ; (n − p + 1) : nombre de termes.
Application 8 (wn) arithmétique, w2 = 7 et w9 = −14.
  1. Trouver la raison r et w0.
  2. Donner wn en fonction de n.
  3. Évaluer S = w5 + w6 + ⋯ + w30.
Exercice 3 u0 = 2, un+1 = 5un − 1un + 3, vn = 1un − 1.
  1. Montrer que un > 1 pour tout n.
  2. Étudier la monotonie de (un).
  3. Montrer que (vn) est arithmétique ; préciser sa raison et son premier terme.
  4. Exprimer vn puis un en fonction de n.
  5. Calculer S = v0 + v1 + ⋯ + vn.

3. Suite géométrique

3.1 Définitions

Activité 4 Soit un = 2 × 3n, n ∈ ℕ.
  1. Contrôler que u1 = 3u0, u2 = 3u1, u3 = 3u2.
  2. Établir que un+1 = 3un pour tout n.

Chaque terme s’obtient en multipliant le précédent par 3 : la suite est géométrique de raison q = 3.

Définition (un)n∈I est géométrique s’il existe un réel q tel que (∀n ∈ I) : un+1 = q·un. Le réel q est la raison.
Exemples Montrons que un = −7 × 5n est géométrique, et que vn = n² + 5 ne l’est pas.
Application 9 u0 = 3, un+1 = 34un + 2, vn = un − 8. Démontrer que (vn) est géométrique, donner sa raison et son premier terme.

3.2 Terme général

Propriété Si (un)n∈I est géométrique de raison q et de premier terme up :
un = up × qn−p   pour tout n ≥ p.
Remarque Si p = 0 : un = u0qn. Si p = 1 : un = u1qn−1.
Exemple u2 = 316 et u5 = 31024. On a u5 = u2 × q³, donc q³ = u5u2 = 164 = (14)³, d’où q = 14. Ainsi un = 316 × (14)n−2 = 3 × (14)n.
Application 10 (vn) géométrique de raison q = 3, v1 = 2. 1. Déterminer v5. 2. Écrire vn en fonction de n.

3.3 Somme de termes consécutifs

Propriété Soit (un) géométrique de raison q, p ≤ n, Sn = up + up+1 + ⋯ + un.
  • Si q ≠ 1 : Sn = up × 1 − qn−p+11 − q.
  • Si q = 1 : Sn = (n − p + 1) × up.
up : premier terme de la somme ; (n − p + 1) : nombre de termes.
Remarque Pour tout q ∈ ℝ* \ {1} : 1 + q + q² + ⋯ + qn = 1 − qn+11 − q.
Application 11 (un) géométrique de raison q = 2 avec u3 = 5. Calculer S = u3 + u4 + ⋯ + u20.
Exercice 4 u0 = 0, un+1 = 2un + 3un + 4, vn = un − 1un + 3.
  1. Montrer que 0 < un < 1 pour tout n.
  2. En déduire la monotonie de (un).
  3. Montrer que (vn) est géométrique ; préciser sa raison et son premier terme.
  4. Exprimer vn puis un en fonction de n.
  5. Calculer S = v0 + v1 + ⋯ + vn.
